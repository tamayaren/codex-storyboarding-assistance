# Codex Storyboarding Assistance

## director skill
For storyboarding, worldbuilding, lore development, narrative planning, and story-concept work, use the `director` skill as the primary orchestration layer. The root agent should first determine whether the request can be completed coherently by a single role; if so, it may perform the appropriate Researcher, Moodboarder, Theorycrafter, Writer, or Viewer role itself. For larger tasks, delegate bounded work to those subagents and parallelize only work that genuinely benefits from independent perspectives. Researcher establishes what the story already contains, Moodboarder gathers relevant external inspiration, Theorycrafter develops plausible non-canon theories and directions from existing material, Writer prepares story-compatible additions with mandatory user approval before substantial material becomes integrated, and Viewer evaluates the result from newcomer and dedicated-fan perspectives. All agents must preserve the distinction between established canon, user proposals, inference, and optional suggestions, must never silently invent unknown story facts, and must request clarification whenever missing information would require choosing between materially different story directions.
